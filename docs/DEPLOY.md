# VPS dan AWS Lambda
Deploy manual melalui Actions setelah CI sukses. Siapkan Ubuntu, PHP >= 8.2, Composer, Node 22, MySQL, Nginx/Apache, TLS, akses Git untuk user deploy, serta database backup.
Lokasi asumsi `/var/www/meal-order` dengan document root `/var/www/meal-order/public`. Clone main, buat `.env` production (APP_DEBUG=false, APP_URL=https://domain-anda, DB credentials, QUEUE_CONNECTION=database), jalankan key:generate hanya pertama kali. Jangan menjalankan seeder demo di production. Pastikan storage dan bootstrap/cache dapat ditulis oleh web server. Atur worker Supervisor/systemd untuk `php artisan queue:work --tries=3`; restart otomatis bila gagal. Siapkan secrets GitHub VPS_HOST, VPS_USER, VPS_KEY, VPS_KNOWN_HOSTS (verifikasi fingerprint secara independen). Tambahkan approval environment production. Uji restore backup dan rollback sebelum deploy nyata. Workflow contoh bukan bukti deploy.
AWS Lambda: buat function Python 3.12, upload handler.py sebagai zip, handler `handler.lambda_handler`. Buat Function URL atau API Gateway dengan kontrol akses/rate limit yang sesuai. Uji payload `{"items":[{"price":"15000","quantity":2}]}`; response estimate 30000.00. Endpoint hanya estimasi, bukan penentu harga checkout. Untuk demo lokal jalankan `python -m unittest discover -s serverless/quote`. Integrasi HTTP opsional hanya jika endpoint memang dapat diakses oleh server; simpan URL di .env. Jangan kirim kredensial AWS atau data pribadi ke endpoint.

GD + fileinfo dan PHP upload/post limits wajib untuk foto. Jangan aktifkan MEAL_SEED_DEV_ACCOUNTS; buat akun dengan `php artisan meal:admin`. Backup database dan storage secara berpasangan. Jalankan CI dan smoke test sebelum deployment.
