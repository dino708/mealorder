# Panduan presentasi
1. Buka katalog melalui QR statis. Jelaskan satu penjual, customer/admin, pickup, pembayaran manual.
2. Rashad: pencarian, filter, kartu Shadow DOM, detail, keranjang, upload preview, tampilan responsif.
3. Noe: admin membuat kategori dan menu dengan foto; tunjukkan file Laravel Storage, path relatif MySQL, edit tanpa/ganti foto, stok dan jadwal PO; checkout menggunakan transaksi dan snapshot.
4. Aldino: login customer, akses admin ditolak, middleware/policy, API dan struktur MVC.
5. Bagus: event checkout dan worker; admin konfirmasi → processing → ready → completed setelah pembayaran manual; pelanggan refresh tracking; laporan data asli. Jelaskan CI/CD dan status deployment yang sebenarnya.
6. Tunjukkan ERD, hasil uji nyata, batasan dan perbaikan; jangan mengklaim AWS Lambda/VPS sudah deploy jika belum. Delivery adalah opsi V4 yang dinonaktifkan untuk cakupan milestone.
