# GitHub workflow
Repository: https://github.com/dino708/mealorder.git
Jangan push saat pengujian lokal. Ketua dan tim harus menyepakati baseline dan branch terlebih dahulu. Clone ke folder terpisah: `git clone https://github.com/dino708/mealorder.git`. Cek `git status`, `git fetch --all`, `git branch -a`. Jika baseline belum ada, ketua integrasikan setelah review dan uji; jangan overwrite pekerjaan teman. Gunakan main sebagai release dan develop sebagai integrasi jika disepakati. Buat branch dari develop yang terbaru (`git switch develop; git pull --ff-only; git switch -c frontend`, contoh Rashad; jika branch sudah ada pakai `git switch frontend`). Branch PIC ada di PEMBAGIAN-TUGAS.md.
Edit file modul, jalankan test, `git diff`, stage file yang benar saja dengan `git add <path>`, commit pesan yang mencerminkan perubahan nyata, `git push -u origin <branch>`, PR ke develop. Review minimal satu teman; perbaiki konflik dengan membaca kedua perubahan dan uji ulang; jangan pakai force push untuk menyembunyikan histori. Setelah semua PR lulus, integrasikan develop ke main. Jika baseline sudah memuat semua fitur, tiap anggota harus benar-benar mengembangkan atau memperbaiki dan menguji bagian miliknya; jangan membuat commit palsu.
